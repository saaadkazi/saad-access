## 🚀 Local Development

Follow these steps to run the project locally on your machine:

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/saaadkazi/saad-access.git
    cd saad-access
    ```

2.  **Install Dependencies:**
    ```bash
    npm install
    ```

3.  **Run Development Server:**
    ```bash
    npm run dev
    ```

4.  **Build for Production:**
    ```bash
    npm run build
    ```
    This bundles the application using Vite and places the production-ready assets inside the `/dist` directory.
